# Professional Portfolio

A responsive personal portfolio built with React to present professional experience, selected projects, technical writing, and contact information in a polished, accessible interface.

## Technical Skills

### Cloud & DevOps

- **AWS** — Cloud infrastructure and managed services
- **DevOps** — Collaborative delivery practices and workflow automation
- **Kubernetes** — Container orchestration and scalable deployments
- **Ansible** — Repeatable configuration management and infrastructure automation
- **Docker** — Portable containerized development and delivery
- **Jenkins** — Continuous integration and continuous delivery pipelines

### Application Development

- React.js, Next.js, and Redux
- TypeScript and Node.js
- HTML and CSS
- GitHub-based collaboration and version control

## Portfolio Features

- Responsive, mobile-first presentation
- Light and dark themes
- Animated project and skill showcases
- Dedicated sections for projects, articles, and contact details

## Local Development

```bash
npm install
npm start
```

Run `npm test` for the test suite or `npm run build` to create a production build.
